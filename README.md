# Slime Mould-biomimicry
# Physarum Polycephalum-Inspired Optimization

## Algorithms, Applications, and Cross-Domain Network Optimization

A multidisciplinary research project inspired by the biological behavior of *Physarum polycephalum* (slime mould).

This work explores how slime mould-inspired adaptive networks can be applied across:

- Graph Optimization
- Shortest Path Algorithms
- Communication Networks
- Protein-Protein Interaction Networks
- Power Grid Optimization

## Abstract

This research investigates Physarum-inspired optimization techniques across multiple engineering and biological domains, including graph-theoretic shortest path computation, communication network routing, protein-protein interaction network optimization, and adaptive power grid conductance systems.

The study demonstrates how decentralized biological behavior can inspire robust, fault-tolerant computational models capable of solving complex optimization problems.
